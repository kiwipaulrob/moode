SendSpin

Settings
Version
$_select[sendspin_update_btn] Update SendSpin Updates the SendSpin CLI to the latest version using uv tool upgrade. The SendSpin service will be restarted after the update.
Metadata
Track metadata and cover art are polled from Home Assistant via the sendspin-metadata-sink service.
Volume control
Software volume (internal). Hardware volume control is disabled because the USB DAC has no hardware mixer. Volume is controlled from the Music Assistant controller.
ALSA device
sendspin (routes through ALSA plug → plughw:0,0 → SMSL USB AUDIO)
